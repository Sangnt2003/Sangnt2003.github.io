10. Resource Cleanup Guide

In this step, we’ll systematically clean up all AWS resources created during the workshop to avoid ongoing charges.

Critical: Follow the cleanup steps in the exact order shown below. Deleting resources out of order may cause dependency errors.

Step 1: Disable CloudFront Distribution

  1. Open the CloudFront Console
  2. Select your distribution
  3. Click Edit → Change Distribution state to Disabled
  4. Click Save changes

Distribution disabling takes 15-20 minutes. You cannot delete a distribution until it’s fully disabled.

Step 2: Delete Application Load Balancer

  1. Open the EC2 Console → Load Balancers
  2. Select your load balancer → Actions → Delete
  3. Confirm deletion by typing the load balancer name
  4. Navigate to Target Groups → Select target group → Delete

Step 3: Terminate EC2 Instances

  1. Go to EC2 Console → Instances
  2. Select your caching-app-server instance
  3. Instance state → Terminate instance
  4. Confirm termination
  5. Repeat for any test instances created during the workshop

Step 4: Delete ElastiCache Redis Cluster

  1. Open ElastiCache Console → Redis OSS caches
  2. Select your product-cache cluster
  3. Actions → Delete
  4. Configure deletion options:
    • Create final backup: No
    • Type cluster name: product-cache
  5. Click Delete
  6. Navigate to Subnet groups → Delete redis-subnet-group

Redis cluster deletion takes 5-10 minutes.

Step 5: Delete DAX Cluster

  1. Open DynamoDB Console → DAX → Clusters
  2. Select your product-dax-cluster
  3. Actions → Delete
  4. Confirm deletion by typing the cluster name
  5. Navigate to Subnet groups → Delete dax-subnet-group

DAX cluster deletion takes 10-15 minutes.

Step 6: Delete DynamoDB Table

  1. In DynamoDB Console → Tables
  2. Select the ProductCatalog table
  3. Actions → Delete table
  4. Configure deletion options:
    • Create backup before deleting: Unchecked
    • Type table name: ProductCatalog
  5. Click Delete table

Step 7: Delete CloudFront Distribution

  1. Return to CloudFront Console
  2. Verify your distribution shows “Disabled” status
  3. Select the distribution → Delete
  4. Confirm deletion

Step 8: Delete IAM Roles

  1. Open IAM Console → Roles
  2. Search for and delete these roles:
    • CachingAppRole
    • DAXServiceRole
  3. For each role: Select → Delete → Type role name to confirm

Step 9: Delete VPC and Networking Resources

  1. Open VPC Console → Security Groups
  2. Delete custom security groups in this order:
    • app-sg
    • redis-sg
    • dax-sg
    • alb-sg

You cannot delete the default security group. Only delete the custom ones you created.

  1. Go to Your VPCs
  2. Select your caching-workshop-vpc
  3. Actions → Delete VPC
  4. Confirm deletion by typing “delete”

Deleting the VPC will automatically delete associated subnets, route tables, internet gateway, and NAT gateways.

Step 10: Clean Up CloudWatch Resources

  1. CloudWatch Console → Dashboards

    • Delete MultiLayerCachingDashboard

  2. Alarms → All alarms

    • Select all workshop-related alarms → Delete

  3. Log groups

    • Delete /aws/ec2/caching-app log group

Step 11: Delete SNS Topics

  1. Open SNS Console → Topics
  2. Select the caching-alerts topic
  3. Delete → Type “delete me” to confirm

Step 12: Verify Complete Cleanup

Check each service to ensure all resources are deleted:

✅ Verification Checklist

EC2 Console:

  • Instances: Terminated
  • Load Balancers: Deleted
  • Target Groups: Deleted

VPC Console:

  • VPC: Deleted
  • Security Groups: Only default remaining
  • Subnets: Deleted
  • NAT Gateways: Deleted

ElastiCache Console:

  • Redis Clusters: Deleted
  • Subnet Groups: Deleted

DynamoDB Console:

  • Tables: Deleted
  • DAX Clusters: Deleted
  • DAX Subnet Groups: Deleted

CloudFront Console:

  • Distributions: Deleted

CloudWatch Console:

  • Dashboards: Deleted
  • Alarms: Deleted
  • Log Groups: Deleted

SNS Console:

  • Topics: Deleted

IAM Console:

  • Custom Roles: Deleted

Step 13: Check Billing Dashboard

  1. Go to Billing Dashboard
  2. Verify no ongoing charges for workshop resources

It may take up to 24 hours for all charges to stop appearing in your billing dashboard after resource deletion.

Troubleshooting Common Issues

Cannot Delete VPC

Cause: Resources still depend on the VPC Solution: Check for remaining ENIs, verify all instances terminated

Cannot Delete Security Group

Cause: Security group still referenced by other resources Solution: Ensure all instances and load balancers are deleted first

CloudFront Distribution Won’t Delete

Cause: Distribution not fully disabled Solution: Wait for “Disabled” status (up to 20 minutes)

DAX Cluster Deletion Fails

Cause: Cluster still being accessed Solution: Stop all applications, wait a few minutes, try again
