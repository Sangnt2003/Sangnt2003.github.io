Khởi Chạy EC2 Instance

Trong bước này, chúng ta sẽ khởi chạy một EC2 instance để host ứng dụng Node.js của chúng ta. Instance này sẽ được cấu hình với software và permissions cần thiết để tương tác với các caching layers của chúng ta.

Bước 1: Điều Hướng Đến EC2 Console

  1. Mở AWS Management Console
  2. Điều hướng đến EC2 service

  1. Nhấp Launch Instance

Bước 2: Cấu Hình Instance Details

Cấu Hình Cơ Bản

  1. Cấu hình basic instance settings:

    • Name: caching-app-server
    • Application and OS Images: Amazon Linux 2023 AMI
    • Architecture: 64-bit (x86)

Instance Type

  1. Chọn instance type:

    • Instance type: t3.micro
    • vCPUs: 2
    • Memory: 1 GiB

t3.micro đủ cho workshop này. Trong production, chọn instance types dựa trên CPU và memory requirements của ứng dụng.

Key Pair

  1. Cấu hình key pair cho SSH access:

    • Key pair: Tạo mới hoặc chọn existing
    • Nếu tạo mới: Key pair name: caching-workshop-key

Download và lưu trữ an toàn private key file của bạn. Bạn sẽ cần nó để SSH vào instance.

Bước 3: Cấu Hình Network Settings

VPC và Subnet

  1. Cấu hình network settings:

    • VPC: Chọn caching-workshop-vpc của bạn
    • Subnet: Chọn public subnet (cho internet access)
    • Auto-assign public IP: Enable

Security Group

  1. Cấu hình security group:

    • Security group: Chọn existing app-sg
    • Xác minh nó cho phép HTTP (80), custom TCP (3000), và SSH (22)

Bước 4: Cấu Hình Storage

  1. Cấu hình storage settings:

    • Size: 8 GiB (default)
    • Volume type: gp3
    • IOPS: 3000
    • Throughput: 125 MB/s

Bước 5: Thêm User Data Script

Advanced Details

  1. Mở rộng phần Advanced details

User Data Script

  1. Thêm user data script sau để tự động cài đặt Node.js và dependencies: 
#!/bin/bash

# Update system
yum update -y

# Install development tools
yum groupinstall -y "Development Tools"
yum install -y git

# Install Node.js using NodeSource repository
curl -fsSL https://rpm.nodesource.com/setup_18.x | bash -
yum install -y nodejs

# Install PM2 for process management
npm install -g pm2

# Create application directory
mkdir -p /home/ec2-user/caching-app
chown ec2-user:ec2-user /home/ec2-user/caching-app

# Install CloudWatch agent
yum install -y amazon-cloudwatch-agent

# Create log directory
mkdir -p /var/log/caching-app
chown ec2-user:ec2-user /var/log/caching-app

# Set up environment
echo 'export NODE_ENV=production' >> /home/ec2-user/.bashrc
echo 'export PATH=$PATH:/usr/bin' >> /home/ec2-user/.bashrc

# Log completion
echo "User data script completed at $(date)" >> /var/log/user-data.log

User data script chạy tự động khi instance boot lần đầu. Nó cài đặt Node.js, PM2, và các tools cần thiết khác.

Bước 6: Tạo IAM Role cho EC2

Điều Hướng Đến IAM Console

  1. Mở IAM Console trong tab mới
  2. Nhấp Roles → Create role

Cấu Hình Trusted Entity

  1. Chọn trusted entity:
    • Trusted entity type: AWS service
    • Service: EC2

  1. Nhấp Next

Attach Permissions

  1. Tìm kiếm và attach các policies sau:

    • AmazonDynamoDBFullAccess
    • AmazonElastiCacheFullAccess
    • CloudWatchAgentServerPolicy

Trong production, sử dụng các policies hạn chế hơn theo nguyên tắc least privilege. Tạo custom policies chỉ cho phép truy cập đến specific resources.

  1. Nhấp Next

Name và Create Role

  1. Cấu hình role details:
    • Role name: CachingAppRole
    • Description: IAM role for caching application server

  1. Nhấp Create role

Bước 7: Attach IAM Role Đến Instance

Modify IAM Role

  1. Quay lại EC2 launch configuration
  2. Trong Advanced details, tìm IAM instance profile
  3. Chọn CachingAppRole

Nếu role không xuất hiện trong dropdown, đợi vài phút để nó propagate, hoặc refresh trang.

Bước 8: Review và Launch

Review Configuration

  1. Review tất cả instance settings:

  2. Xác minh:

    • Instance name và AMI
    • Instance type và key pair
    • Network và security configuration
    • Storage settings
    • IAM role attachment

Launch Instance

  1. Nhấp Launch instance

Instance launch mất 2-3 phút. User data script sẽ chạy tự động trong first boot, có thể mất thêm 3-5 phút.

Bước 9: Giám Sát Instance Launch

Kiểm Tra Instance Status

  1. Điều hướng đến EC2 Dashboard → Instances

  1. Giám sát instance status:
    • Instance State: Running
    • Status Checks: 2/2 checks passed

Xem Instance Details

  1. Nhấp vào instance để xem details:

  2. Ghi lại Public IPv4 address và Private IPv4 address:

    • Public IP: Cho SSH access từ internet
    • Private IP: Cho internal VPC communication

Bước 10: Kết Nối Đến Instance

Cho Windows users: Cài đặt MobaXterm để SSH access dễ dàng với built-in file transfer và terminal features.

Download MobaXterm: MobaXterm Website

SSH Connection

  1. Kết nối đến instance của bạn bằng MobaXterm

Xác Minh Installation

  1. Kiểm tra Node.js và npm đã được cài đặt:
# Check Node.js version
node --version

# Check npm version
npm --version

# Check PM2 installation
pm2 --version

# Check if application directory exists
ls -la /home/ec2-user/caching-app

Kiểm Tra User Data Logs

  1. Xác minh user data script hoàn thành thành công:
# Check user data logs
sudo cat /var/log/user-data.log

# Check cloud-init logs
sudo cat /var/log/cloud-init-output.log

Bước 11: Cấu Hình AWS CLI (Tùy chọn)

Cài Đặt AWS CLI

  1. Cài đặt AWS CLI v2:
# Download AWS CLI
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"

# Install unzip if not available
sudo yum install -y unzip

# Unzip and install
unzip awscliv2.zip
sudo ./aws/install

# Verify installation
aws --version

Test AWS Permissions

  1. Test IAM role đang hoạt động:
# Test DynamoDB access
aws dynamodb list-tables

# Test ElastiCache access
aws elasticache describe-cache-clusters

# Check current identity
aws sts get-caller-identity

Bước 12: Ghi Lại Instance Information

Ghi lại thông tin sau cho application configuration:

EC2 Instance Information

  • Instance ID: i-xxxxxxxxxxxxxxxxx
  • Instance Type: t3.micro
  • Public IP: xx.xx.xx.xx
  • Private IP: 10.0.x.x
  • Security Group: app-sg
  • IAM Role: CachingAppRole

Network Configuration

  • VPC: caching-workshop-vpc
  • Subnet: Public subnet
  • Availability Zone: us-east-1a (hoặc AZ đã chọn của bạn)

Khắc Phục Các Vấn Đề Thường Gặp

Vấn Đề: Không Thể SSH Đến Instance

Nguyên Nhân Có Thể:

  • Security group không cho phép SSH
  • Wrong key pair hoặc permissions
  • Instance không ở public subnet

Giải Pháp:

  • Xác minh security group cho phép SSH (port 22) từ IP của bạn
  • Kiểm tra key pair permissions: chmod 400 your-key.pem
  • Đảm bảo instance ở public subnet với public IP

Vấn Đề: User Data Script Thất Bại

Nguyên Nhân Có Thể:

  • Network connectivity issues
  • Package installation failures
  • Insufficient permissions

Giải Pháp:

  • Kiểm tra /var/log/cloud-init-output.log cho errors
  • Manually chạy installation commands
  • Xác minh internet connectivity từ instance

Vấn Đề: AWS CLI Commands Thất Bại

Nguyên Nhân Có Thể:

  • IAM role không attached
  • Insufficient permissions
  • Region configuration issues

Giải Pháp:

  • Xác minh IAM role được attached đến instance
  • Kiểm tra IAM role có required policies
  • Set AWS region: aws configure set region us-east-1

Security Best Practices

Instance Security

  • SSH Key Management: Secure private key storage
  • Security Groups: Least-privilege access rules
  • IAM Roles: Service-specific permissions only
  • System Updates: Regular security patches

Network Security

  • Public Subnet: Chỉ cho instances cần internet access
  • Private Communication: Sử dụng private IPs cho internal traffic
  • Security Groups: Hoạt động như virtual firewalls

Các Bước Tiếp Theo

EC2 instance của bạn giờ đã sẵn sàng cho application deployment! Bạn có:

✅ EC2 Instance chạy Amazon Linux 2023
✅ Node.js và npm installed và configured
✅ PM2 cho production process management
✅ IAM Role với necessary AWS permissions
✅ Network Configuration cho multi-layer caching access
✅ SSH Access cho management và deployment

Instance Capabilities:

  • Node.js Runtime: Sẵn sàng cho application deployment
  • AWS SDK Access: Có thể tương tác với DynamoDB, ElastiCache, và DAX
  • Process Management: PM2 cho production-grade application hosting
  • Monitoring: CloudWatch agent cho metrics và logs

Giữ instance của bạn an toàn bằng cách thường xuyên update packages và tuân theo AWS security best practices.

Tiếp theo, chúng ta sẽ deploy ứng dụng multi-layer caching đến instance này.
