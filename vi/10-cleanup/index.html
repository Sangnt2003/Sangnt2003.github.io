10. Hướng Dẫn Dọn Dẹp Tài Nguyên

Trong bước này, chúng ta sẽ dọn dẹp một cách có hệ thống tất cả các tài nguyên AWS được tạo trong workshop để tránh các khoản phí liên tục.

Quan Trọng: Thực hiện các bước dọn dẹp theo đúng thứ tự được hiển thị bên dưới. Xóa tài nguyên không đúng thứ tự có thể gây ra lỗi dependency.

Bước 1: Vô Hiệu Hóa CloudFront Distribution

  1. Mở CloudFront Console
  2. Chọn distribution của bạn
  3. Nhấp Edit → Thay đổi Distribution state thành Disabled
  4. Nhấp Save changes

Việc vô hiệu hóa distribution mất 15-20 phút. Bạn không thể xóa distribution cho đến khi nó được vô hiệu hóa hoàn toàn.

Bước 2: Xóa Application Load Balancer

  1. Mở EC2 Console → Load Balancers
  2. Chọn load balancer của bạn → Actions → Delete
  3. Xác nhận xóa bằng cách gõ tên load balancer
  4. Điều hướng đến Target Groups → Chọn target group → Delete

Bước 3: Terminate EC2 Instances

  1. Đi đến EC2 Console → Instances
  2. Chọn instance caching-app-server của bạn
  3. Instance state → Terminate instance
  4. Xác nhận termination
  5. Lặp lại cho bất kỳ test instances nào được tạo trong workshop

Bước 4: Xóa ElastiCache Redis Cluster

  1. Mở ElastiCache Console → Redis OSS caches
  2. Chọn cluster product-cache của bạn
  3. Actions → Delete
  4. Cấu hình deletion options:
    • Create final backup: No
    • Type cluster name: product-cache
  5. Nhấp Delete
  6. Điều hướng đến Subnet groups → Xóa redis-subnet-group

Việc xóa Redis cluster mất 5-10 phút.

Bước 5: Xóa DAX Cluster

  1. Mở DynamoDB Console → DAX → Clusters
  2. Chọn product-dax-cluster của bạn
  3. Actions → Delete
  4. Xác nhận xóa bằng cách gõ tên cluster
  5. Điều hướng đến Subnet groups → Xóa dax-subnet-group

Việc xóa DAX cluster mất 10-15 phút.

Bước 6: Xóa DynamoDB Table

  1. Trong DynamoDB Console → Tables
  2. Chọn table ProductCatalog
  3. Actions → Delete table
  4. Cấu hình deletion options:
    • Create backup before deleting: Unchecked
    • Type table name: ProductCatalog
  5. Nhấp Delete table

Bước 7: Xóa CloudFront Distribution

  1. Quay lại CloudFront Console
  2. Xác minh distribution của bạn hiển thị trạng thái “Disabled”
  3. Chọn distribution → Delete
  4. Xác nhận xóa

Bước 8: Xóa IAM Roles

  1. Mở IAM Console → Roles
  2. Tìm kiếm và xóa các roles này:
    • CachingAppRole
    • DAXServiceRole
  3. Cho mỗi role: Chọn → Delete → Gõ tên role để xác nhận

Bước 9: Xóa VPC và Networking Resources

  1. Mở VPC Console → Security Groups
  2. Xóa custom security groups theo thứ tự này:
    • app-sg
    • redis-sg
    • dax-sg
    • alb-sg

Bạn không thể xóa default security group. Chỉ xóa những cái custom mà bạn đã tạo.

  1. Đi đến Your VPCs
  2. Chọn caching-workshop-vpc của bạn
  3. Actions → Delete VPC
  4. Xác nhận xóa bằng cách gõ “delete”

Xóa VPC sẽ tự động xóa các subnets, route tables, internet gateway, và NAT gateways liên quan.

Bước 10: Dọn Dẹp CloudWatch Resources

  1. CloudWatch Console → Dashboards

    • Xóa MultiLayerCachingDashboard

  2. Alarms → All alarms

    • Chọn tất cả alarms liên quan đến workshop → Delete

  3. Log groups

    • Xóa log group /aws/ec2/caching-app

Bước 11: Xóa SNS Topics

  1. Mở SNS Console → Topics
  2. Chọn topic caching-alerts
  3. Delete → Gõ “delete me” để xác nhận

Bước 12: Xác Minh Dọn Dẹp Hoàn Tất

Kiểm tra từng dịch vụ để đảm bảo tất cả tài nguyên đã được xóa:

✅ Danh Sách Kiểm Tra Xác Minh

EC2 Console:

  • Instances: Terminated
  • Load Balancers: Deleted
  • Target Groups: Deleted

VPC Console:

  • VPC: Deleted
  • Security Groups: Chỉ còn default
  • Subnets: Deleted
  • NAT Gateways: Deleted

ElastiCache Console:

  • Redis Clusters: Deleted
  • Subnet Groups: Deleted

DynamoDB Console:

  • Tables: Deleted
  • DAX Clusters: Deleted
  • DAX Subnet Groups: Deleted

CloudFront Console:

  • Distributions: Deleted

CloudWatch Console:

  • Dashboards: Deleted
  • Alarms: Deleted
  • Log Groups: Deleted

SNS Console:

  • Topics: Deleted

IAM Console:

  • Custom Roles: Deleted

Bước 13: Kiểm Tra Billing Dashboard

  1. Đi đến Billing Dashboard
  2. Xác minh không có khoản phí liên tục cho tài nguyên workshop

Có thể mất đến 24 giờ để tất cả các khoản phí ngừng xuất hiện trong billing dashboard sau khi xóa tài nguyên.

Khắc Phục Các Vấn Đề Thường Gặp

Không Thể Xóa VPC

Nguyên Nhân: Tài nguyên vẫn phụ thuộc vào VPC Giải Pháp: Kiểm tra ENIs còn lại, xác minh tất cả instances đã terminated

Không Thể Xóa Security Group

Nguyên Nhân: Security group vẫn được tham chiếu bởi tài nguyên khác Giải Pháp: Đảm bảo tất cả instances và load balancers đã được xóa trước

CloudFront Distribution Không Xóa Được

Nguyên Nhân: Distribution chưa được vô hiệu hóa hoàn toàn Giải Pháp: Đợi trạng thái “Disabled” (lên đến 20 phút)

DAX Cluster Deletion Thất Bại

Nguyên Nhân: Cluster vẫn đang được truy cập Giải Pháp: Dừng tất cả ứng dụng, đợi vài phút, thử lại
