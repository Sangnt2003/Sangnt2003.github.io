Thiết Lập DynamoDB DAX

DynamoDB Accelerator (DAX) là một in-memory cache được quản lý hoàn toàn, có tính khả dụng cao cho DynamoDB, cung cấp cải thiện hiệu suất lên đến 10 lần. Trong bước này, chúng ta sẽ tạo một DAX cluster để cung cấp microsecond-latency access đến ProductCatalog table của chúng ta.

Tổng Quan Kiến Trúc DAX

DAX cung cấp:

  • Microsecond latency cho cached reads
  • Write-through caching cho consistency
  • Automatic cache management với TTL
  • Multi-AZ deployment cho high availability

Bước 1: Tạo DAX Subnet Group

Điều Hướng Đến DAX Console

  1. Trong DynamoDB Console, nhấp DAX ở navigation bên trái

  2. Nhấp Subnet groups trong left menu

  3. Nhấp Create subnet group

Cấu Hình Subnet Group

  1. Nhập subnet group details:

    • Subnet group name: dax-subnet-group
    • Description: Subnet group for DAX cluster
    • VPC ID: Chọn caching-workshop-vpc của bạn

  1. Chọn availability zones và subnets:
    • Chọn cả hai private subnets từ các AZ khác nhau
    • Điều này đảm bảo high availability cho DAX cluster

  1. Nhấp Create subnet group

Bước 2: Tạo IAM Role cho DAX

Điều Hướng Đến IAM Console

  1. Mở IAM Console trong tab mới
  2. Nhấp Roles → Create role

Cấu Hình Role

  1. Chọn trusted entity:
    • Trusted entity type: AWS service
    • Service: DynamoDB Accelerator (DAX)

  1. Nhấp Next

Attach Permissions

  1. Tìm kiếm và chọn các policies sau:
    • AmazonDynamoDBFullAccess (cho workshop purposes)

Trong production, sử dụng các policies hạn chế hơn theo nguyên tắc least privilege. Tạo custom policies chỉ cho phép truy cập đến specific DynamoDB tables.

  1. Nhấp Next

Name và Create Role

  1. Cấu hình role details:
    • Role name: DAXServiceRole
    • Description: Service role for DynamoDB DAX cluster

  1. Nhấp Create role

Bước 3: Tạo DAX Parameter Group (Tùy chọn)

Điều Hướng Đến Parameter Groups

  1. Quay lại DAX Console
  2. Nhấp Parameter groups trong left menu

  1. Nhấp Create parameter group

Cấu Hình Parameter Group

  1. Nhập parameter group details:
    • Parameter group name: dax-custom-params
    • Description: Custom parameters for DAX cluster

  1. Nhấp Create

Cho workshop này, chúng ta sẽ sử dụng default parameters. Trong production, bạn có thể muốn tune parameters như query-ttl-millis và record-ttl-millis.

Bước 4: Tạo DAX Cluster

Start Cluster Creation

  1. Nhấp Clusters ở left navigation
  2. Nhấp Create cluster

Bước 1: Choose Cluster Nodes

  1. Nhập cluster configuration:

    • Cluster name: product-dax-cluster
    • Description: DAX cluster for product catalog caching
    • Node type: dax.t3.small
    • Cluster size: 3 nodes

3 nodes cung cấp high availability qua nhiều AZs. Cho production workloads, cân nhắc larger node types dựa trên memory và throughput requirements của bạn.

  1. Nhấp Next

Bước 2: Configure Networks

  1. Cấu hình VPC settings:

    • VPC ID: Chọn vpc-xxxxxxxxx (caching-workshop-vpc)
    • VPC environment nơi DAX cluster của bạn sẽ chạy

  1. Cấu hình subnets:

    • Subnets: Nhấp Choose subnets
    • Chọn cả hai private subnets từ các AZ khác nhau
    • DAX sẽ chọn IP addresses từ những subnets đó và assign chúng cho cluster nodes

  1. Cấu hình access control:

    • Security Group: Chọn dax-sg (thay thế default security group)
    • Security group hoạt động như firewall kiểm soát network access đến DAX cluster của bạn

  1. Nhấp Next

Bước 3: Configure Security

  1. Cấu hình IAM service role:

    • IAM service role: Chọn DAXServiceRole
    • Role này cho phép DAX truy cập DynamoDB thay mặt bạn

  1. Cấu hình encryption settings:
  • Cluster endpoint encryption: Disabled (cho workshop)
  • Encryption at rest: Disabled (cho workshop)

Trong production environments, luôn enable encryption in transit và at rest để tuân thủ security.

  1. Nhấp Next

Bước 4: Verify Advanced Settings (Tùy chọn)

  1. Cấu hình advanced settings:
  • Parameter group: default.dax1.0
  • Maintenance window: No preference
  • Notification topic: None

  1. Nhấp Next

  1. Xác minh:

    • Node type và count
    • VPC và subnet configuration
    • Security group và IAM role
    • Encryption settings

  2. Nhấp Create cluster

Bước 7: Test DAX Connectivity

Launch Test Instance

  1. Launch một temporary EC2 instance trong private subnet của bạn để test DAX connectivity:

    • AMI: Amazon Linux 2023
    • Instance type: t3.micro
    • Subnet: Một trong các private subnets của bạn
    • Security group: app-sg

Install DAX Client

  1. Kết nối đến test instance của bạn và cài đặt DAX client:
# Update system
sudo yum update -y

# Install Node.js for testing
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
source ~/.bashrc
nvm install 18
nvm use 18

# Install DAX client
npm install amazon-dax-client aws-sdk

Test DAX Connection

  1. Tạo test script để xác minh DAX connectivity:
// test-dax.js
const AmazonDaxClient = require('amazon-dax-client');
const AWS = require('aws-sdk');

// Configure AWS region
AWS.config.update({region: 'us-east-1'});

// Create DAX client
const daxClient = new AmazonDaxClient({
    endpoints: ['product-dax-cluster.xxxxxx.dax-clusters.us-east-1.amazonaws.com:8111'],
    region: 'us-east-1'
});

// Test function
async function testDAX() {
    try {
        const params = {
            TableName: 'ProductCatalog',
            Key: {
                ProductID: 'PROD001',
                Category: 'Electronics'
            }
        };
        
        console.log('Testing DAX connection...');
        const result = await daxClient.get(params).promise();
        console.log('✅ DAX connection successful!');
        console.log('Product data:', JSON.stringify(result.Item, null, 2));
    } catch (error) {
        console.error('❌ DAX connection failed:', error);
    }
}

testDAX();
  1. Chạy test:
node test-dax.js

  • Cache TTL: Configurable (default: 5 phút cho queries)

Khắc Phục Các Vấn Đề Thường Gặp

Vấn Đề: DAX Cluster Creation Thất Bại

Nguyên Nhân Có Thể:

  • Insufficient subnet group configuration
  • IAM role permissions issues
  • Security group misconfiguration

Giải Pháp:

  • Xác minh subnet group có subnets trong nhiều AZs
  • Kiểm tra IAM role có DynamoDB permissions
  • Đảm bảo security group cho phép port 8111

Vấn Đề: Không Thể Connect Đến DAX

Nguyên Nhân Có Thể:

  • Security group chặn traffic
  • Incorrect endpoint configuration
  • Network connectivity issues

Giải Pháp:

  • Xác minh security group cho phép inbound traffic trên port 8111
  • Kiểm tra DAX endpoint URL và port
  • Đảm bảo client ở cùng VPC với DAX cluster

Vấn Đề: Poor Cache Performance

Nguyên Nhân Có Thể:

  • Inappropriate node size
  • High cache miss ratio
  • Network latency

Giải Pháp:

  • Giám sát CloudWatch metrics cho bottlenecks
  • Cân nhắc larger node types cho memory-intensive workloads
  • Tối ưu query patterns cho better cache utilization

Performance Optimization Tips

Cache Effectiveness

  • Query Patterns: Thiết kế queries để maximize cache hits
  • TTL Configuration: Cân bằng freshness vs. performance
  • Node Sizing: Chọn appropriate memory cho dataset của bạn

Monitoring Best Practices

  • Thiết lập CloudWatch alarms cho high CPU hoặc low cache hit rates
  • Giám sát network utilization để identify bottlenecks
  • Track error rates để identify connectivity issues

Các Bước Tiếp Theo

DynamoDB DAX setup của bạn giờ đã hoàn thành! Bạn có:

✅ DAX Cluster với 3 nodes qua nhiều AZs
✅ Subnet Group được cấu hình cho private network access
✅ IAM Role với appropriate DynamoDB permissions
✅ Security Group cho phép application access
✅ CloudWatch Monitoring enabled cho performance tracking
✅ Connectivity tested và verified

DAX Benefits Achieved:

  • Microsecond latency cho cached DynamoDB operations
  • Automatic cache management với write-through consistency
  • High availability với multi-AZ deployment
  • Seamless integration với existing DynamoDB APIs

DAX trong suốt với ứng dụng của bạn - bạn có thể sử dụng cùng DynamoDB SDK calls, và DAX sẽ tự động cache kết quả cho subsequent access nhanh hơn.

Tiếp theo, chúng ta sẽ thiết lập ElastiCache Redis cho application-level caching để tạo complete multi-layer caching architecture của chúng ta.
